# Campus Event Management System

## Project Description

Campus Event Management System is a web application that helps university students view upcoming events and register for them. Authorized users can create, update, and manage events.

## Project Objectives

* Display university events.
* Allow students to register for events.
* Provide event search and category filters.
* Manage events through authorized users.
* Use Git and GitHub for team collaboration.
